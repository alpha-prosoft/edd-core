# projectname

edd-core service generated by `edd.scaffold`.

```bash
clojure -M:test:unit      # unit tests (mock DAL)
./format.sh               # format, ./format.sh check in CI
```

- `src/projectname/service.clj` — distributor, stores, authentication, remote deps resolver
  (HTTP, Cognito credentials) and security, shared by every runtime
- `src/projectname/module.clj` — registers the domain namespaces
- `src/projectname/auth.clj` — authentication of HTTP requests (Cognito)
- `src/projectname/filters.clj` — runtime filters around the handler
- `src/projectname/main.clj` — runtime entry point (`MAIN_CLASS` in `Dockerfile`)
- `src/projectname/item.clj` — example command, event and query with `:auth` roles

Security is enforced: every command and query needs an `:auth` role, and
effects run as `:non-interactive`, so keep that role on actions effects call.

With Undertow, run locally with `clojure -M -m projectname.main` (`Port` env,
default 8080). It also consumes the service's command and event sources;
`:consume []` on `undertow/start` disables that. Lambda uses handler `lambda.Handler`.
